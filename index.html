FIELD NOTES

How to hold the pass

  1. Recruit. Draw slayers with wisteria. Each draw costs 1.
  2. Position. Select a roster card, then choose a grass tile beside the trail. They attack demons in range automatically.
  3. Evolve. Three copies of the same character and rank fuse into one stronger slayer — even if they're already deployed.
  4. Survive. Start each wave when you're ready. Demons that reach the gate cost you health. Clear waves to earn more wisteria.
